# 商品背景图生成

为教材习题解析数字商品生成一张**背景视觉素材**。文字、数字、Logo 由 Python 后期精确排版叠加，因此生成的图片中**不要包含任何文字**。

## 风格

- 干净、专业、适合教育类数字商品，避免幼稚卡通。
- 主色：深蓝灰 + 暖金点缀；留出大面积低对比度区域供文字排版。
- 构图：左侧或上方留白，右侧/下方放置抽象的纸张、几何线条、公式符号剪影。
- 不出现可识别的教材封面、出版社 Logo、人物肖像或受版权保护的角色。
- 不出现水印文字、乱码文字、伪文字。
- 分辨率适合电商主图，纵向构图。

## 禁止

- 任何真实文字、数字、字母串。
- 伪造的数学公式（可有意虚化或抽象化，但不要写成看似正确的公式）。
- 侵权素材、知名 IP、名人肖像。

## 输出

只生成图像。主体应简洁，便于叠加中文标题、卖点与品牌标识。
