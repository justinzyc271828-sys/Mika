# 分册与套装销售 SKU 验收样张

本目录是文链家 v1.1 的**合成数据验收案例**，用于证明“教材 → 分册生产 → 单册 SKU → 套装 SKU → 独立商品图片 / 交付清单”的完整链路。

> 重要说明：本样张没有调用 OpenAI 或 DeepSeek，也没有上传百度网盘或创建分享。两册教材、习题和解析均由确定性测试生成器合成，仅用于验证生产流程与文件结构，不代表真实教材、真实 AI 解答或真实销售商品。封面为程序自主设计，不是出版社原版封面。

## 验收教材与商品

| 层级 | 编号 | 内容 |
| --- | --- | --- |
| 教材实体 | `LA001` | 《线性代数》，2 册，测试出版社 |
| 生产实体 | `LA001-U` | 上册，4 页 / 2 章 / 4 道习题，4/4 已复核 |
| 生产实体 | `LA001-L` | 下册，4 页 / 2 章 / 4 道习题，4/4 已复核 |
| 单册 SKU | `LA001-U` | 上册习题详解，¥3.99 |
| 单册 SKU | `LA001-L` | 下册习题详解，¥3.99 |
| 套装 SKU | `LA001-B` | 上下册套装，¥5.00；单册原价合计 ¥7.98，省 ¥2.98 |

套装只引用两个生产实体已经生成的 PDF，不复制 PDF，不重复调用 AI，不重复生成内容。

## 本地实测结果

- 两个生产任务均为 `completed`，两个生产实体均为 `packaged`。
- 每册 4/4 道习题通过自动复核；两册合计 8/8。
- 套装清单包含 2 个 PDF 引用和 7 张商品图，共 9 个交付文件；PDF 未被复制。
- 三个 SKU 分别生成 7 张商品图。
- 套装 `验收记录.json` 为 `needs_review`，原因只有两个：合成教材没有出版社原版封面（未冒充），以及尚未执行百度网盘上传 / 分享。不是生产或价格错误。

## 文件与路径

`文件清单.json`、`TWO_VOLUME_ACCEPTANCE.json` 保留了生成时的绝对路径和 SHA-256，用于证明来源与文件一致性。复制到本目录后绝对路径不再指向本机文件；请以文件清单中的文件名和哈希为准，不要把旧路径当作安装路径。

## 如何复现

在项目根目录执行：

```powershell
$env:PYTHONUTF8=1
.\.venv\Scripts\python.exe .\tests\two_volume_smoke.py
```

脚本会重建 `.tmp_two_volume_test`。测试使用 `FixtureSolver` / `FixtureVerifier`，不会发起任何外部请求。
