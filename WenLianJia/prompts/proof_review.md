# 证明题专项复核

在通用复核规则之外，证明题还必须满足以下检查。若任一项无法确认，不得判 `pass`。

## 检查清单

1. **命题边界**：题目中的量词（任意/存在）、范围、维数、正负、整数性是否写清。
2. **定理条件**：每一步引用的定理，其前提是否已逐条验证。
3. **逻辑闭合**：是否从已知推出结论，是否存在循环论证、逆命题误用、充分必要混淆。
4. **遗漏情况**：零向量、空集、退化情形、端点、分母为零、不可逆等是否排除或单独处理。
5. **构造与唯一性**：存在性证明是否给出构造；唯一性证明是否验证两个对象相等。
6. **反例检验**：对关键断言尝试极端或小规模反例；若发现反例，必须判错误。
7. **结论形式**：最终结论是否与题目要求完全一致，没有偷换概念。

## 输出

沿用 `reconcile_review.md` 的 JSON 结构，并在 `checks` 中逐项列出上述检查结果。任何 `blocker` 必须导致 `needs_revision` 或 `reject`。
