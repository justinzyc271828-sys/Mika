This folder contains output actually produced by the application, but it is a
**pipeline test fixture**, not a real textbook product.

- Source: `tests/fixtures/sample_linear_algebra.pdf`, a synthetic 5-page
  Chinese textbook generated by `tests/fixtures/build_sample.py`.
- Answers: generated by a deterministic `FixtureSolver`; review verdicts by a
  deterministic `FixtureVerifier`.  **No OpenAI call was made.**
- Cover note in the PDF states: `流程测试样张：使用确定性样例解答验证生产链路，不代表真实 AI 结果。`
- Full PDF: 12 pages, 259,027 bytes.
- Quick PDF: 2 pages, 177,442 bytes.
- Images: seven 1080×1440 PNGs generated from the actual fixture PDF and real
  database counts.
- Delivery records: nine hashed files; cloud/share checks remain `pending`
  because no credentials were available.  Absolute paths in these records point
  to the original fixture run (`.tmp_pipeline_test`); the same files are copied
  here under `商品图片/` and the two PDFs in this folder.  The SHA-256 values and
  sizes are the evidence; the paths are provenance, not install locations.

Use this package to inspect layout, watermark, formulas, image composition and
record structure.  Do not sell or present it as a real textbook solution.
